### Criterio de reasignación (uso < 40%) — vigente hasta julio

Recordamos el criterio vigente sobre el indicador de uso de licencia (umbral: 40%):

- **Primera ocasión** que un usuario no alcanza el 40% de uso: procede justificación y la licencia se mantiene.
- **Segunda ocasión** que no alcanza el 40%: la licencia ya no se asigna a partir del mes siguiente.

### Nuevo criterio — consistencia de casos de uso (a partir de agosto)

A partir de agosto se incorpora un criterio adicional de análisis, independiente del anterior: se revisará que los casos de uso documentados (mínimo 3 por mes) correspondan con las actividades justificadas para la asignación de la licencia. Los casos de uso que no sean consistentes con dichas actividades serán motivo de revisión para la reasignación.

### Actualización de umbral — a partir de agosto

El umbral mínimo de uso de 40% aplica para la evaluación de julio. **A partir de agosto, el umbral mínimo de uso se incrementa de 40% a 70%.**
